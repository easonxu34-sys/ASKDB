# 图表编辑意图精简与统一编译设计

> 当前状态：自然语言修改图表功能已于 2026-10-06 移除。本文保留为历史设计记录；手动图表编辑仍复用配置归一化与持久化逻辑。

## 已确定的范围

用户确认保留全部现有编辑能力，只精简模型协议。按“缩小意图协议和统一编译 → 能力上下文和一次纠错 → 统一预览确认”推进。在当前工作区增量修改，不提交、推送、部署或查询真实数据。

本设计更新旧版自然语言编辑设计中的模型协议和立即保存行为；认证、查询确认、同轮结果关联、缓存隔离、撤销历史及 ECharts 产物契约继续沿用。

## 术语和链路

- **模型意图**：模型输出的短操作列表，只表达用户要求改变的项。
- **内部意图**：程序生成的现有 `ChartEditIntent`，作为兼容 API 响应保留，不再直接用作模型输出 schema。
- **配置编译**：将内部意图或手动草稿归一化成现有 `ChartViewConfiguration`，并用实际查询产物校验。
- **预览**：局部 UI 草稿；尚未写入 override 或历史。

链路：原始指令和有界显示上下文 → 严格模型操作对象 → 确定性转换和业务策略 → BFF 现有内部意图响应 → 共用配置归一化与校验 → 预览 → 用户应用 → 共用缓存提交 → ECharts。

## 模型协议

根对象只包含 `operations`、`query_operation` 和 `clarification_code`。操作使用 `kind` 和与该操作相关的参数；无宽 patch、任意 JSON、SQL、代码或模型生成的用户可见文本。至多 24 个操作；类别配色至多八项。

保留图表类型、方向、维度/指标选择、隐藏指标、标题、字段标签、排序、四种格式、标签/图例显示、度量/类别配色和当前结果 Top N。格式使用按模式拆开的操作参数，避免要求填写不相关的 null。字段继续使用现有结果中的精确名称，显示标签用于理解；不另建字段 ID 生命周期。

小数位使用独立 `set_precision` 操作。只改小数位时保留当前格式模式和单位；只改格式模式时由程序保留当前小数位，不要求模型复制现有配置。

操作顺序不承担隐式覆盖语义；同一目标的相同操作可去重，不同值视为冲突并要求澄清。空意图及查询/澄清/操作不一致组合拒绝。未提及的项保持当前配置。

例如“改成柱状图，把收入设为蓝色”仅需以下模型输出；程序随后转换成旧内部意图，内部补丁的 null 占位不再由模型填写：

```json
{
  "operations": [
    {"kind": "set_chart_type", "value": "bar"},
    {"kind": "set_metric_color", "field": "revenue", "color": "blue"}
  ],
  "query_operation": null,
  "clarification_code": null
}
```

不生成排序操作表示保留当前排序；`restore_result_order` 明确恢复查询结果行顺序。Top N 自己决定匹配的度量排序，模型不重复生成排序。兼容性必须调整排序时由程序执行，并通过前后配置摘要展示。

## 能力与纠错

能力上下文在服务端根据校验后的显示上下文派生，包括字段类型、可选维度/数值字段、当前指标、支持的图表类型、Top N 范围、饼图截断约束、固定调色板及源单位要求。不接收客户端能力声明作为授权；不传查询行、类别列表、SQL、密钥或工具。

能力是解释辅助；前端仍需使用真实结果校验。服务端业务策略保留字段、单位、查询范围等检查，不靠关键词覆盖一个合法且明确的澄清。

结构化解析/操作协议校验失败最多纠错一次。第二次请求只附固定安全原因码，不附原始模型响应、provider 错误、失败字段值或原始异常文本。业务歧义、冲突、未知字段/单位直接澄清；provider 不支持、调用失败、超时和取消不纠错。两次调用共用原路由超时和 lease 的 finally 释放。

## 共用配置编译

Web 纯函数承担类型切换、维度切换、颜色保留/清理、指标格式默认值、失效排序和 Top N 清理规则。手动草稿和自然语言编辑调用同一规则；`validateChartView` 继续负责最终有效性。只有确实不兼容的设置被清除，柱状图与折线图之间切换保留仍兼容的系列颜色。

无关标题、标签、格式、颜色和排序不被改写。缺失字段、歧义类别、不支持的单位或图表组合整体失败，不部分保存。

## 统一预览确认

自然语言展示编辑解释成功后打开现有编辑对话框，填入编译后的草稿并展示确定性摘要；取消不持久化，应用才进入共用提交函数并记录 natural_language 来源。手动调整预览也保持这次提案来源。源结果、线程、消息或基础视图变更使提案过期，禁止保存。

混合查询/展示请求继续先预览查询消息、显式确认查询。新 turn 完成且查询/图表结果唯一匹配后，展示编辑在新结果上重新校验；已确认的混合操作可沿用现有暂存提案整体提交。失败、取消、结果错配或不兼容都丢弃暂存，旧图保持不变。查询确认与本地图表应用是不同操作。

## 验收

1. 模型 schema 不包含旧 patch；只输出相关操作参数。
2. 标题编辑保留排序/颜色/格式；恢复原始行序有显式操作。
3. 每项现有能力可确定性转换成旧内部意图，BFF 和持久化格式保持兼容。
4. 手动和自然语言配置切换规则一致；编译不修改输入或查询行。
5. 格式错误可修正一次；第二次仍错安全失败；业务澄清及 provider 不支持只调用一次。
6. 纠错消息和能力上下文不含查询行、SQL、provider 原始错误或模型原始响应。
7. 自然语言展示提案确认前不保存、不发起查询；取消和过期提案均不保存。
8. 原 API 授权、超时、取消和 lease 清理测试通过；现有查询确认和撤销链路通过。
9. 本地测试不代表真实模型兼容性或浏览器端到端验证；分别报告。
