# AskDB 图表交互编辑器首版设计

## 目标

在 AI 推荐图表之后提供用户可控的修正能力。用户能够调整图表类型、维度、指标、指标显隐、排序、标题、图表字段显示名、单位和数值格式，并能恢复 AI 推荐配置。中文业务名称和单位准确性优先于增加图表类型。

首版是现有图表卡片的交互编辑扩展。编辑使用当前成功查询结果，不重新调用 Agent 或数据库，不改变 SQL、查询行或原始查询表格。

## 当前实现边界

现有图表链路已经定义了这些边界：

- Agent 为成功查询结果生成 `QueryResultArtifact`，并可生成引用它的 `ChartArtifact` 推荐。
- 图表只引用同一轮查询结果；Web 从该结果解析图表，不接收模型提供的 ECharts option 或 JavaScript。
- Web 通过 `agent-chat-adapter.ts` 接收查询和图表事件，将结果保存在 `local-thread-adapter.tsx` 的用户、会话、轮次缓存中，并在历史回放时重建图表。
- `chart-output.ts` 根据已校验的图表 artifact 和查询 artifact 生成白名单 ECharts 配置；`chart-result.tsx` 负责图表卡片渲染。

首版用户编辑只扩展 Web 展示层及其本地结果缓存。查询安全闸、Agent 工具、SSE 数据库查询协议和只读 SQL 链路不变。

## 方案与决定

### 方案对比

1. **保存独立用户覆盖项（采用）**：保留 Agent 推荐和查询结果不变，单独保存用户配置。能够恢复推荐，且复用现有按用户、会话、轮次组织的浏览器缓存。
2. **直接改写 Agent 图表 artifact**：初期实现较简单，但会覆盖 AI 推荐，需要额外备份才能恢复，也混淆模型输出与用户状态。
3. **服务端保存图表配置**：可以跨设备同步，但当前图表和结果行仅由本地结果缓存供历史回放，需要新增服务端数据模型和 API，首版不采用。

### 核心术语

| 术语 | 含义 |
| --- | --- |
| 查询结果 `QueryResultArtifact` | 成功查询返回的字段类型、字段名和原始行，是图表编辑的数据源。只读、不在编辑器中修改。 |
| 推荐图表 `ChartArtifact` | Agent 为查询结果生成的初始图表建议，保留为只读基线。 |
| 用户图表配置 `ChartViewOverride` | 用户对推荐配置的可选覆盖项，引用同一 `source_result_id`，只保存图表显示设置。 |
| 推荐配置 | 从 `ChartArtifact` 确定的初始图表类型、维度、指标和标题，以及首版中性显示默认值。 |

## 用户体验

### 图表卡片与编辑器

- 图表卡片右上角显示“编辑图表”和全屏按钮。
- “编辑图表”打开响应式对话框。桌面端左侧显示设置、右侧显示使用当前草稿的即时预览；窄屏使用纵向布局，操作按钮固定在底部。
- 设置依次分为“图表类型”“字段”“排序”“标题与数值格式”“标签和图例”。
- “取消”丢弃未应用草稿；“应用”先校验并写入本地缓存，成功后更新卡片并关闭对话框。
- 只在存在有效推荐图表和有效来源查询结果时显示编辑入口。不可绘制、过期或损坏的结果继续显示查询表格和简短原因。
- 编辑器支持键盘操作、焦点约束和清楚的控件标签；关闭对话框后焦点回到“编辑图表”。验证错误关联到对应设置项。

### 恢复推荐

- 用户配置不同于推荐时，编辑器显示“恢复 AI 推荐”。
- 点击该按钮立即将推荐配置写入覆盖项并更新当前图表，不要求再点击“应用”。当前未保存草稿会被舍弃。若缓存写入失败，不改变已保存图表并提示失败。
- 当用户配置已与推荐一致时隐藏该按钮。恢复是可逆的，之后仍可再次编辑，因此不额外要求确认。

### 图表展示选项

- 折线图和柱状图的数据标签默认关闭；饼图默认显示分类标签。
- 多指标图默认显示图例，单指标图默认隐藏图例。用户可以在编辑器中分别切换标签和图例显示，选择会随配置保存。
- 全屏是临时显示状态，不写入配置。退出全屏后保留图表配置。
- 长字段名可以在坐标轴上截断；tooltip 和图例保留完整显示名。

## 配置模型

用户覆盖项保存在每个轮次的结果 artifact 列表中，使用独立 kind，不修改查询或推荐 artifact。建议契约如下：

```json
{
  "kind": "chart_view_override",
  "schema_version": 1,
  "source_result_id": "turn-scoped-result-id",
  "view": {
    "chart_type": "bar",
    "dimension_field": "region",
    "metric_fields": ["revenue", "profit_rate"],
    "bar_orientation": "horizontal",
    "title": "各地区销售额与利润率",
    "field_labels": {
      "region": "地区",
      "revenue": "销售额",
      "profit_rate": "利润率"
    },
    "sort": { "mode": "metric", "field": "revenue", "direction": "desc" },
    "format_by_field": {
      "revenue": {
        "mode": "unit_scale",
        "unit_family": "CNY",
        "source_unit": "yuan",
        "display_unit": "ten_thousand_yuan",
        "decimal_places": 2
      },
      "profit_rate": {
        "mode": "percent",
        "encoding": "ratio_0_1",
        "decimal_places": 1
      }
    },
    "show_data_labels": false,
    "show_legend": true
  }
}
```

`view` 至少包含图表类型、一个维度、一个至四个指标、标题、字段别名、排序、每个指标的格式，以及标签和图例状态。柱状图方向仅在柱状图时有意义。字段引用使用查询结果字段名；用户可编辑的标题和别名不参与字段解析。

推荐配置的默认排序为：时间维度的折线图按时间升序，其余维度保留查询原序；柱状方向为纵向；指标格式为原始数值和自动精度。标签、图例按“图表展示选项”中的默认规则确定。

`format_by_field[field]` 使用以下白名单结构：

- `mode: raw`：不缩放、不加单位，`decimal_places` 为 `auto` 或整数 0–6。
- `mode: unit_scale`：必须提供 `unit_family`、`source_unit` 和 `display_unit`，字段必须来自同一固定单位族；只做该单位族的比例换算。
- `mode: suffix`：提供用户输入的纯文本 `suffix`，只加显示后缀、不缩放。
- `mode: percent`：必须提供 `encoding`，取 `ratio_0_1` 或 `percent_0_100`，以及精度。

首版金额换算只包含用户明确选择的人民币尺度：元、千元、万元、亿元；因子分别为 1、1,000、10,000、100,000,000。换算只在用户选择来源和显示尺度后发生，不执行币种汇率转换。其他单位可用 `suffix` 标注原值，但不能触发缩放。

两个指标设置的单位或尺度不同时，共用值轴并提示“指标单位不同，数值不宜直接比较”；首版不创建双轴或自动归一化。

覆盖项不复制行数据。读写接口按 `(user_id, thread_id, turn_id, source_result_id)` 定位配置；同一图表再次保存时更新原有覆盖项，避免每次编辑都向结果列表追加一个副本。

## 图表、字段和排序规则

### 字段候选项

- 维度只能选择可确认的日期/时间字段或分类字段。
- 指标只能选择 Arrow 类型标识为数值的字段；每张图至少选一个，最多四个。
- 字段类型不在受支持范围时不通过样例值推断数值含义，也不作为可选维度或指标。
- 类型识别按 Arrow 类型白名单进行：`int`、`uint`、`float`、`double`、`decimal`、`numeric` 为数值；`date`、`time`、`timestamp` 为时间；`string`、`large_string`、`bool`、`boolean`、`dictionary` 为分类。struct/list/map/binary/null 和未知类型不支持。
- 指标勾选顺序成为图例顺序。隐藏指标只隐藏该图表系列，不移除或修改查询结果。

### 图表类型

首版保留折线、柱状和饼图，不新增更多图表类型。

- 折线图可用时间或分类维度，使用所选数值指标。
- 柱状图可选择纵向或横向。横向柱状图用于排名，指标降序时高值排在前面。
- 饼图需要一个分类维度、一个指标、最多八个唯一的非空分类，所有指标值必须是有限非负数且合计大于零。饼图不接受截断查询结果，因为未返回的行会令总量占比失真。
- 如果用户选择的类型不满足数据约束，禁用该选项并给出简洁原因；不偷偷切换成另一种图表。

### 原始行与重复分类

- 编辑器不聚合、不删除、不补造查询行。图表使用查询结果中的原始数值。
- 维度值重复时，每条查询行仍单独呈现；分类轴使用行位置作为内部坐标，同时显示原始维度标签，避免将重复值合并成一个类别。tooltip 显示实际维度值和指标值。
- 饼图遇到重复维度值时不可用，不对重复分类求和或去重。
- 空维度显示为空值标记；折线和柱状图中的空指标值作为空缺，不替换成零。饼图若存在空、无效或负指标值则不可用。
- 数值指标值必须是受支持数值列中的有限数值；无效值在折线/柱状图中留为空缺，饼图禁用，不把任意字符串解析成数值。

### 排序

排序选项受图表类型约束：

- 柱状图支持查询原序、维度升序/降序、按一个可见指标升序/降序。
- 折线图支持查询原序和维度升序/降序；时间维度默认按时间升序。不提供按指标重排时间序列的选项。
- 饼图支持查询原序或按其唯一指标升序/降序。

按指标排序时空值置末尾，排序值相同时保持查询原始行顺序。时间字段按时间顺序比较，而不是按格式化后的本地化标签排序。

排序只改变图表的行投影，查询表保留数据库返回的顺序。查询结果被截断时，图表明确标记只展示已返回的行。

## 中文名称、单位与格式

### 标题和字段显示名

- 图表标题、维度显示名和指标显示名均可由用户直接编辑。
- 默认标题来自推荐图表，默认字段显示名来自查询结果字段名；首版不调用模型生成或猜测中文名称。
- 字段别名仅作用于图表、坐标轴、图例和 tooltip。查询表继续展示原始字段名与原始值，保持来源可追溯。

### 数值和单位

每个指标单独设置，默认格式为**原值、单位未设置、精度自动**，不做缩放。

- 用户选择明确的原值单位和显示单位后，系统才能执行支持的同一单位族换算，例如“元 → 万元”；换算比例来自固定映射，不由模型推断。
- 用户可以只添加单位后缀而不换算数值。界面明确区分“只加显示标签”和“按单位换算”。自定义后缀永远不触发缩放或币种兑换。
- 未选择完整且兼容的原单位、显示单位时保持原始值，不套用转换比例。
- 精度可设为自动或 0–6 位。坐标轴、数据标签和 tooltip 使用同一格式规则；格式化和舍入只影响显示，不改写查询 artifact。
- 多指标共享一个值轴。指标配置的单位不同或尺度不同时，界面显示“指标单位不同，数值不宜直接比较”提示；不会自动建双轴或归一化。用户仍可继续展示，并从各指标 tooltip 查看原值和单位。

### 百分比

百分比格式必须显式选择原值编码：

- **比率 0–1**：例如 `0.12 → 12%`，显示时乘以 100。
- **百分数 0–100**：例如 `12 → 12%`，显示时不再乘以 100。

未选编码时该指标仍按原始数字显示，不加 `%`，也不缩放。饼图中的“分类占比”是指标值相对饼图总和的占比，与指标自身若配置为百分比的格式含义分开显示。

## 保存与历史回放

- 覆盖项写入当前用户和会话已有的每轮本地结果缓存，与推荐图表及查询结果同轮关联。
- 页面实时编辑和历史重放使用相同的配置解析逻辑：先校验推荐 artifact 和查询 artifact，再按 `source_result_id` 找到覆盖项并校验字段、类型及格式。
- 覆盖项仅在本浏览器可用，不跨设备同步；这是现有查询结果缓存的限制。跨设备同步属于后续服务端存储设计。
- 覆盖项体积保持很小，只存显示状态，不复制行数据；遵守现有结果缓存大小上限和轮次淘汰策略。若旧轮次的查询 artifact 因缓存上限被淘汰，旧图表配置也随之不可回放。
- 用户配置最多四个系列、1,000 个查询返回行；超过 1,000 行的结果按已有截断边界绘制，并显示截断提示。不会因为标签打开而下载或查询更多数据。
- 写入失败时保留之前已保存配置，提示“保存失败”，编辑器保持打开，不宣称新值已持久化。

## 错误和回退

- 配置字段不存在、类型不兼容、饼图条件失效或版本未知：忽略用户覆盖项，优先显示仍有效的推荐配置，并提示已回退。
- 推荐图表或其来源查询结果缺失/损坏：不渲染图表。来源查询 artifact 有效时，保留查询表格和可理解的不可用原因；来源 artifact 已被既有缓存策略淘汰时，不承诺重建行表格，但保留服务端历史文本并提示查询结果缓存已失效。
- 编辑过程中配置不完整时禁用应用，并在对应控件旁显示原因；例如没有可见指标、百分比编码未选、金额单位不兼容或饼图分类重复。
- ECharts 动态加载或渲染失败时显示紧凑错误状态。查询结果表格和助手文本不受影响。
- ECharts option 由 Web 代码从已校验 artifact、查询结果和用户配置构造。不得接受或合并任意 ECharts JSON、HTML tooltip 或用户脚本。

## 首版包含与不包含

### 包含

- 图表编辑器与即时预览。
- 折线、纵向/横向柱状、饼图的有效切换。
- 维度和指标选择、指标显隐、排序、标题和图表字段别名。
- 显式单位、数值精度、百分比编码、标签和图例设置。
- 全屏查看、一键恢复 AI 推荐、同浏览器历史回放。

### 不包含

- 新增其他图表类型、任意数据过滤、前端重新聚合或补发 SQL。
- AI 猜测中文别名、币种、金额单位或百分比编码。
- 跨设备/跨浏览器同步用户图表设置。
- 双坐标轴或自动单位转换。若多指标配置的单位不同，显示明确提示，用户自行决定是否继续比较。

## 验收标准

1. 用户可把有效图表切换为折线、纵/横柱状或饼图；字段不足时明确禁用并说明原因。
2. 用户可更换一个维度、选择一至四个数值指标、隐藏部分系列，并按维度或指标排序；这些操作不修改或重新请求查询结果。
3. 重复分类不会被静默聚合或丢弃；饼图只接受唯一分类、有效非负值和未截断结果。
4. 用户设置的标题和字段别名出现在图表、图例和 tooltip；原始查询表仍展示原字段名和值。
5. 金额单位默认未设置；单位换算仅在用户明确选择兼容来源和显示单位时发生。百分比示例 `0.12` 和 `12` 按所选编码分别显示为 `12%`，不做自动猜测。
6. 数据标签、图例和排序保存并在刷新/历史回放后恢复；全屏状态退出后不写入配置。
7. “恢复 AI 推荐”一次点击即持久化并还原原始推荐，之后仍可再次编辑。
8. 覆盖项只在对应用户、会话、轮次和查询结果内生效，不跨结果或跨用户复用。
9. 本地缓存写入失败时提示失败且保留此前配置；未知或无效覆盖项安全回退，查询表和助手文本继续可用。
10. 编辑器不会触发 Agent 轮次、SSE 查询事件或新的 SQL 执行。

## 预计实施边界

首版预计只改 Web 图表和结果缓存链路：

- `askdb-web/lib/chat-output.ts`：用户覆盖项类型、校验、从推荐配置构造默认视图。
- `askdb-web/lib/chart-output.ts`：根据有效视图配置构造白名单 ECharts option；统一标签、tooltip 和单位格式。
- `askdb-web/lib/agent-chat-adapter.ts`、`askdb-web/lib/local-thread-adapter.tsx`：按来源结果读取/更新用户覆盖项并在回放时还原。
- `askdb-web/components/assistant-ui/elements/chart-result.tsx`、`askdb-web/components/assistant-ui/elements/thread.aui.tsx`：编辑器、即时预览、复位、全屏和保存状态。

Agent 返回的 `ChartArtifact` 和 `QueryResultArtifact`、查询安全链路、后端 API 不需要因首版编辑器改变。
