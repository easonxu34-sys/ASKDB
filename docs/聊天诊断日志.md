# 个人记忆开关与查询澄清诊断

后端新增 `ASKDB_CHAT_DIAG` 日志，级别为 INFO，沿用 Uvicorn 的控制台输出配置。先确保运行服务加载了修改后的代码；开发模式 `--reload` 可自动加载，本机打包部署或 Docker 部署需要按原部署方式更新后再复测。

## 复测与收集

保持账号、所选模型和数据源一致，分别开启、关闭个人记忆，每次新建会话，输入：`按照下单时间分析一下每天的销售金额趋势`。建议每个状态重复两次，判断是否只是单次模型判断波动。

如果使用仓库的本机部署脚本，复测前打开日志监视：

```bash
tail -n 0 -F "$HOME/Library/Application Support/ASKDB-Agent/logs/agent.stderr.log" | rg --line-buffered 'ASKDB_CHAT_DIAG'
```

其他启动方式可从 Agent 控制台筛选 `ASKDB_CHAT_DIAG`。提供每轮从 `request_received` 到 `stream_finished` 的日志，同时说明哪轮开启、关闭，以及页面最终是澄清还是成功。不要提供环境变量文件、凭据或完整数据库结果。

## 日志字段与判断

- 所有记录包含 `schema`、`event`、`thread_ref`、`turn_ref`，后两项是标识符的哈希摘要，用来关联同一轮日志。
- `personal_prepare`：开关、绕过标志、是否为记忆管理请求、记录数量和问题指纹。
- `personal_recall_skipped`：无可用记忆时跳过匹配；`personal_match_input/result`：有记忆时的候选数量、降级状态及是否澄清。
- `runtime_acquired`：数据源、revision、MDL、模型配置版本摘要，以及查询审查模型类型、temperature 指纹和业务上下文指纹。temperature 为配置值摘要，不代表服务商实际采样参数。
- `personal_recall_finished`：是否产生提前回复、采用的记忆数量与个人上下文指纹。
- `context_assembled`、`stream_entered`：保留的历史条数、共享召回状态、消息和参考资料指纹。新会话应核对 `history_count=0`。
- `personal_management_reply` / `personal_short_circuit`：个人记忆阶段直接回复，未进入正常查询审查。
- `gate_input`：本轮实际审查输入及其各部分的 SHA-256 和字符数。两轮 `input.sha256` 一致表示审查消息文本相同；不包含提供方隐式参数或外部状态。
- `gate_result`：`READY`、`CLARIFY`、`INTERNAL`、`INVALID`，以及输出指纹和耗时。`INVALID` 表示输出不符合预期格式，会沿原逻辑要求澄清；`gate_error` 只记录异常类型及耗时。
- `clarification_review`：澄清安全审核是否通过、是否使用兜底文案。
- `agent_started/finished`：是否执行查询 Agent、工具开始/完成/错误次数、是否取得成功查询结果、答复指纹和耗时。
- `answer_review`：最终答复安全审核结果。
- `stream_finished`：流失败状态、turn 收尾与 lease 释放记录。

架构调整后普通查询不再通过 `personal_match_result` 的自由澄清提前结束。新增：`personal_candidates`（类别、版本、场景指纹和规范 payload 键）、`personal_selection`（选择来源摘要）、`personal_semantic_issue`（受控原因码）、`personal_resolution`（解释版本与查询/展示投影指纹）、`query_decision`（最终统一决定）、`personal_override_verified`（当前字段赋值覆盖的来源）和 `presentation_budget_omitted`（可选展示因预算不足跳过）。纯记忆管理仍保留独立回复分支。

如果两轮审查输入、模型和 revision 摘要一致，但 `gate_result.decision` 不同，差异出现在审查模型输出。如果均为 `READY`，则继续比较 Agent 与查询成功记录。如果没有 `gate_input` 而出现个人记忆提前回复记录，则差异发生在个人记忆阶段。

日志不输出原始问题、完整提示词、记忆正文、SQL、工具参数、工具输出、查询结果或凭据。指纹仅支持对比内容是否一致，不能还原内容以判断业务口径是否正确。
